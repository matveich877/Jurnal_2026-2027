УСТАНОВКА ЖУРНАЛА КАК ПРИЛОЖЕНИЯ (офлайн)

Это PWA-приложение: 4 маленьких файла, интернет нужен только один раз
при установке, дальше всё работает офлайн, данные хранятся в телефоне.

СПОСОБ 1 — бесплатный хостинг (рекомендую, 5 минут)
1. Откройте на компьютере https://app.netlify.com/drop
   (можно без регистрации, либо через GitHub/Google)
2. Перетащите мышкой ВСЮ папку zhurnal-app в окно браузера
3. Получите ссылку вида https://random-name-12345.netlify.app
4. Откройте эту ссылку на телефоне:
   • Android/Chrome: меню (⋮) → «Установить приложение» / «Добавить на главный экран»
   • iPhone/Safari: «Поделиться» → «На экран Домой»
5. Готово: на рабочем столе иконка «Журнал», открывается как приложение,
   работает без интернета.

Другие хостинги, если Netlify не подошёл: GitHub Pages, Vercel, tiiny.host.

СПОСОБ 2 — без хостинга (только Android)
Просто откройте index.html в браузере телефона — журнал и так работает
офлайн как файл, но без иконки на рабочем столе и service worker
(нужно держать файл на телефоне и открывать его из файлового менеджера).

ВАЖНО
• Данные (отметки, оплата) хранятся в самом телефоне внутри приложения.
• Периодически нажимайте «⬇ Экспорт» в приложении и сохраняйте файл
  резервной копии — при смене телефона перенесёте через «⬆ Импорт».
• Обновление журнала: замените index.html на хостинге новой версией,
  приложение на телефоне подхватит её при первом запуске с интернетом.
